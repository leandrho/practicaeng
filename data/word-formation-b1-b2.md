## Ejemplos para practicar en contexto

- **decide → decision:** *I decided to stay.* / *It was a difficult decision.*
- **succeed → success → successful → successfully:** *She succeeded.* / *The project was a success.* / *It was successful.* / *We finished successfully.*
- **care → careful → carefully:** *Be careful.* / *Drive carefully.*
- **differ → difference → different → differently:** *They differ.* / *What's the difference?* / *They're different.* / *I see it differently.*
- **rely → reliability → reliable → reliably:** *I rely on it.* / *Reliability matters.* / *It's reliable.* / *It works reliably.*
