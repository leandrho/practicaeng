# Word Formation B1--B2

Familias de palabras para practicar con tarjetas. La idea es mostrar una
palabra base y tratar de producir sus formas antes de revelar la
respuesta.

> **---** significa que no hay una forma común o útil para este nivel en
> esa categoría.

## Ejemplos para practicar en contexto

-   **decide → decision:** *I decided to stay.* / *It was a difficult
    decision.*
-   **succeed → success → successful → successfully:** *She succeeded.*
    / *The project was a success.* / *It was successful.* / *We finished
    successfully.*
-   **care → careful → carefully:** *Be careful.* / *Drive carefully.*
-   **differ → difference → different → differently:** *They differ.* /
    *What's the difference?* / *They're different.* / *I see it
    differently.*
-   **rely → reliability → reliable → reliably:** *I rely on it.* /
    *Reliability matters.* / *It's reliable.* / *It works reliably.*

## Idea de tarjeta para la app

**Frente:** `DECIDE`\
Intentá producir: noun / adjective / adverb.

**Reverso:** `decision / decisive / decisively`

También podés generar ejercicios tipo:\
`I haven't made a final ______ yet. (DECIDE)` → **decision**
